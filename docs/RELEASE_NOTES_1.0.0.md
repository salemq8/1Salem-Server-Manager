# 1Salem Server Manager 1.0.0

First complete Windows x64 release for vanilla Minecraft Java and vanilla
Palworld dedicated-server management.

This release includes native Client/Agent binaries, official game installation
flows, safe import/update/backup/restore, process and resource control, secure
opt-in LAN pairing, English/Arabic UI, native setup, portable and source
archives, and SHA-256 checksums.

Known release notes:

- Windows 10/11 x64 only.
- No mods, plugins, public tunnels, cloud control, or port-forwarding
  automation.
- LAN must be enabled explicitly and should be used only on trusted Private
  networks.
- Release binaries produced by the local build are not publisher code-signed.
